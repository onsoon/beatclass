# BeAT 실습실

부산교육 AI 튜터 **BeAT(비트)** 1차시(45분) 고등학생 수업용 실습 사이트입니다.

- 바로 열기: `index.html` (인터넷만 연결되어 있으면 브라우저에서 열거나 GitHub Pages로 배포해 쓸 수 있어요)
- 실습 순서: ① 윤리 퀴즈 → ② 안전 약속(약속을 그림으로) → ③ 접속하기 → ④ 질문 만들기 → ⑤ 메뉴별 실습(수업GPT · 개인GPT · AI Agents · Custom AI) → ⑥ 돌아보기
- 실습 자료: `data/` 폴더 (사이트 안에서도 내려받을 수 있어요)

| 파일 | 쓰는 실습 |
| --- | --- |
| 수업GPT_통합과학_탄소순환_학습지 (.docx, .txt) | 수업GPT, AI Agents(퀴즈 코치) |
| 개인GPT_수학_오답노트 (.docx, .txt) | 개인GPT |
| 개인GPT_비문학지문_추천알고리즘.txt | 개인GPT |
| AIAgents_가상설문_스마트폰과수면.csv | AI Agents(발표 코치) |
| CustomAI_자기소개_서식_예시.docx · 작성가이드.txt · 초안_예시.txt | Custom AI 자기소개 멘토링 |
| CustomAI_영어지문_번역연습 (.docx, .txt) | Custom AI 문서번역, AI Agents(영어 단어 짝꿍) |

모든 자료는 수업 연습용으로 새로 만든 예시이며, 설문 데이터와 자기소개 속 인물은 가상입니다.
캐릭터 일러스트 출처: 「2026년 부산교육 AI 튜터 BeAT(비트) 활용 학생 교육 프로그램」 리플릿 (부산광역시교육청 · 부산대학교 AI융합교육원)

## GitHub Pages로 배포하기

Settings → Pages → Build and deployment에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 고르고 저장하면
`https://onsoon.github.io/beatclass/` 주소로 열립니다.
